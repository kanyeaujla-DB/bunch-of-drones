# Problem statement summary

Develop a multi-drone swarm platform using Pluto drones for coordinated formations and synchronized movement. The system is expected to include swarm coordination, trajectory generation, external vision-based positioning, real-time monitoring, and positional drift correction.

## Required tasks
- Line formation with wave effect using four drones.
- Circular formation with wave effect using four drones.

Both tasks must be tested in simulation and demonstrated using physical Pluto drones.

## Core requirements
Drone identification, formation generation, synchronized trajectory planning, position/altitude control as supported by the hardware, collision and separation checks, pre-flight validation, external localization, closed-loop drift correction, monitoring, logging, and safe handling of localization or communication failures.

## Evaluation priorities
Physical swarm execution and formation accuracy (40%); localization and drift correction (20%); synchronization and trajectory execution (15%); safety and fault handling (10%); simulation and algorithm validation (10%); software architecture and documentation (5%).
